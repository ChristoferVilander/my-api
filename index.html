Christofer API

A small personal API that exposes structured information about me, my skills and my work.

Base URL

https://christofervilander.se/api/v1

Available endpoints

  • GET /api/v1 – API overview and available endpoints.
  • GET /api/v1/me – Profile information (name, title, location, bio, focus areas, links).

Example response from /api/v1/me

{
  "name": "Christofer Vilander",
  "title": "IT Product Manager",
  "location": "Borlänge",
  "experience_years": 15,
  "current_role": "Product Area Manager at Lyko"
}

JavaScript example

fetch("https://christofervilander.se/api/v1/me")
  .then(res => res.json())
  .then(data => console.log(data));

Testing this API in Postman

If you want to explore this API in Postman, create a new GET request to https://christofervilander.se/api/v1/me, send the request, and inspect the JSON response. You can then save it in a collection called Christofer API for future use.
